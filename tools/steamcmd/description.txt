[h1]SE Overclock — Ship Upgrade Module System[/h1]

Enhance your ship's combat capabilities by equipping upgrade modules.
Simply place a module into a cockpit inventory and the effect is applied instantly.

[hr][/hr]

[h1]How to Use[/h1]

[b]1. Rename a cockpit to include [Upgrade][/b]
Rename any cockpit block that has an inventory to include [Upgrade] in its name.
Example: [code]Fighter Cockpit [Upgrade][/code]

[b]2. Craft upgrade modules[/b]
Build the desired modules in an Assembler.
Each module starts at Level 1. Higher levels require the previous level as a crafting ingredient.

[b]3. Place the module in the cockpit inventory[/b]
Put the crafted module into that cockpit's inventory. The effect is applied immediately.
Only the highest level of each module type is recognized.

[b]4. Check your current levels[/b]
Open the cockpit's terminal info (Custom Info panel) to see all currently applied module levels.

[h1]Notes[/h1]
[list]
[*] Grinder and drill damage is not affected by upgrade modules.
[*] If a ship has multiple [Upgrade] cockpits, the lowest level among them is used.
[*] All effects are calculated server-side and work correctly in multiplayer.
[/list]
